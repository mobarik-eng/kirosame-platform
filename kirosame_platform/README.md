# Kirosame Platform

A modern real estate rental and sales platform.

## Prerequisites

To run this project, you need **PHP** installed on your computer.

### How to Install PHP on Windows
The easiest way is to install **XAMPP**:
1. Download XAMPP from [apachefriends.org](https://www.apachefriends.org/).
2. Install it.
3. Open the **XAMPP Control Panel** and start **Apache**.

## How to Run the Project

### Option 1: Using the provided script (Requires PHP in PATH)
1. Double-click `run.bat` in this folder.
2. Open [http://localhost:8000](http://localhost:8000).

### Option 2: Using XAMPP
1. Copy the `kirosame_platform` folder to `C:\xampp\htdocs\`.
2. Open your browser and go to `http://localhost/kirosame_platform/`.
